# Учебный проект - анализ сигналов кровотока

## Цель проекта

Мы разрабатываем прибор, который записывает сигнал фотоплетизмограммы (ФПГ) с пальца руки и пальца стопы.

Мне необходимо выделять отдельные пульсовые волны, оценивать их формы и амплитуды, разрабатывать различные индексы.
Одна из первых задач - это разметить эти пульсовые волны.

Необходимо выбрать метод разметки пульсовых волн, устойчивый к возможному затуханию сигнала и шуму на стопе. 

Для я хочу не вручную размечать сигнал, а сделать модулятор: программу, которая будет имитировать сигналы 
с заданными характеристиками, чтобы сравнивать качество работы различных алгоритмов разметки.


## Данные и материалы
- Сигналы кровотока реальных обследуемых `data/private/`
- Информация о формате сигналов `data/signals.md`
- Подробное описание задач в `tasks/`.

## Как работать
- Код для выполнения расчётов в папку `src/` (или в `runs/<папка прогона>`, по контексту задания)
- Код на Python. Запускать только через `.venv\Scripts\python`.
- Установлены: numpy, scipy, pandas, matplotlib, pytest, neurokit2 (версии — в requirements.txt).
- Результаты расчётов и отчёты в папку `runs/`
- Новые знания сохраняются в папку `notes/`
- После каждой задачи — запись в `DIARY.md`: дата, запрос, что сделано,
  результат, точка проверки, итог проверки. Коротко в 2-3 абзаца.
- Формат окончаний строк - CRLF
