# INDEX — карта проекта ФПГ

Обновлено: 2026-10-21. Структура каталогов и их назначение.

## Правила ведения

- Файл описывает только структуру и назначение. Правила работы и критерий
  готовности — в `AGENT.md`, постановки — в `benchmark/`, результаты и метрики —
  в `runs/*/report.md`; здесь они не дублируются.
- Строка дерева: путь и одна фраза о содержимом. Форматы, числа, обоснования
  не переносятся.
- Новый прогон: новый каталог `runs/tN-wX-rY/`, строка в таблице «Прогоны»
  и пересчёт счётчика в таблице «Задачи».
- Прошлые строки не удаляются и не переименовываются; допустимо менять статус
  и ссылку на проверку.
- Дата в шапке обновляется при каждом изменении.

## Дерево

```text
AGENT.md              договор проекта
INDEX.md              этот файл
DIARY.md              журнал задач
REPORT.md             личные наблюдения пользователя
requirements.txt      версии пакетов

checks/               проверки задач: checks.py (T1)

  signals.md          формат записей
  private/            записи пациентов (gitignored)
papers/               исходные PDF статей (gitignored): Charlton 2023, PPG roadmap

runs/                 прогоны, по каталогу на прогон
  t1-w1-r1/           прогон 1 задачи T1, неделя 1
    modulator.py      генератор синтетических пар
    sets/             данные прогона: set_clean, set_baseline, set_hard
    figures.py        построение рисунков
    check_figures.py  численная сверка того, что видно на рисунках
    figures/          fig1_clean.png, fig2_attenuation.png, fig3_missed.png

    real_stats*.json  результаты замеров
    report.md         отчёт прогона (11 разделов)
    checks_output.txt лог проверки
    scratch/          черновики и диагностика
  t1-w2-r1/           прогон 1 задачи T1, неделя 2 (независимое решение)
    modulator.py      генератор: Config, build, пресеты, CLI
    run_official_checks.py  запуск checks/checks.py против этого каталога
    sets/             данные прогона: set_clean, set_baseline, set_hard
    figures.py        построение рисунков из сохранённых CSV
    figures/          рис. 1-3 и facts.json (что изображено)
    check_figures.py  численная сверка того, что видно на рисунках
    probe_real.py     замеры по data/private/, обоснование параметров
    real_stats.json   результаты замеров
    report.md         отчёт прогона (9 разделов)
    checks_*.txt      логи проверок: штатная, по каталогу прогона, рисунки
    scratch/          черновики: diag.py (подбор формы), summary.py (сводка)
notes/                заметки объектов по ontology.yaml (пока отсутствует)
ontology/             заметки классов онтологии: файл <Класс>.md на каждый класс
  build_class_notes.py  генератор заметок классов из ontology.yaml
ontology.yaml         схема онтологии проекта
```

Имя каталога прогона: `runs/tN-wX-rY/` — задача, неделя, номер прогона.
