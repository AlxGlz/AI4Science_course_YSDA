# Анализ пульсовых волн ФПГ «рука — стопа»

[порождено и принято]

Репозиторий Алексея Глазкова для сдачи домашнего задания №1.

Учебный проект курса ШАД «ИИ-ассистенты для исследователя. AI4Science», домашняя работа 1
«Среда и контекст». Наш прибор записывает фотоплетизмограмму (ФПГ) с пальца руки и пальца
стопы; цель — выбрать метод разметки пульсовых волн, устойчивый к затуханию и шуму на
стопе. Работа с агентом курса построена вокруг одной задачи-бенчмарка: каждую неделю
агент дорабатывается, а затем заново решает ту же задачу.
