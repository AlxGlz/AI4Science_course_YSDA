# Замеры по записям прибора

## Что запущено

```text
.venv\Scripts\python runs\t1-w4-r1\probe_real.py
.venv\Scripts\python runs\t1-w4-r1\scratch\probe_delay_sign.py
```

Первый скрипт считает по трём записям `data/private/` длительность, DC, СКО шума по вторым разностям, ЧСС по пикам руки в полосе 0.5–8 Гц, задержку стопы кросс-корреляцией и отношение амплитуд стопа/рука. Второй пересчитывает задержку независимым способом — сопоставлением пиков каналов, — чтобы не зависеть от соглашения о знаке в кросс-корреляции.

## Итог

Обе оценки задержки совпали в пределах 3 мс: +81/+84/+81 мс по пикам против 75–84 мс по кросс-корреляции, знак один и тот же (стопа позже). Шум: рука 24.2–34.8, стопа 15.6–18.3 отсчётов. DC: рука 13.6–15.9 тыс., стопа 19.9–25.1 тыс. Отношение амплитуд стопа/рука 1.11–1.38 по полосовым сигналам.

## Границы

Записи только читались; пациентские данные в заметки и в git не копировались. Замеры описывают исправный прибор и трёх добровольцев; статистики по пациентам с ЗПА нет. Формат файлов — `data/signals.md`, столбцы 1 (рука) и 7 (палец стопы).
